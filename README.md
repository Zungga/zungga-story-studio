# Zungga Story Studio

A tiny web tool that plays a story as a 3D animated scene with an ElevenLabs voiceover, and records it as a ready-to-post vertical MP4 (1080 × 1920, 30 fps) for Reels, Shorts and the Zungga app.

A story is a **data file** (JSON), not a video: the studio builds the 3D scene, runs the camera moves, speaks each line, and records it all in one click. A new story only needs a new file.

- Requirements, story format and the first story ("My Parents Gave Me Pocket Money"): [`docs/requirements.md`](docs/requirements.md)

**Status:** planning — nothing built yet.

> The ElevenLabs API key is never stored in this repository or in any page code.
